## Worum es geht

Ein unbekanntes Instrument rendert per SSR mit Status 200 und „nicht gefunden“; jeder Fehler (auch 502/504 vom BFF, seit O3 sauber gemeldet) erscheint als „nicht gefunden“.

## Wo

`src/Frontend/app/pages/instrumente/[id].vue`

## Vorschlag

Bei 404 `throw createError({ statusCode: 404 })`, bei anderen Fehlern eine eigene Meldung („Dienst gerade nicht erreichbar“). Test mit `mountSuspended`/`registerEndpoint`.

## Fertig, wenn

- [ ] Unbekanntes Instrument → HTTP 404; 502/504 → eigene Meldung.
