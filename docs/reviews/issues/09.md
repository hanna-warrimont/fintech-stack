## Worum es geht

Das öffentlich erreichbare Frontend setzt keine Security-Header (CSP, `X-Frame-Options`/`frame-ancestors`, HSTS, `Referrer-Policy`).

## Wo

`src/Frontend/nuxt.config.ts`

## Vorschlag

`routeRules: { '/**': { headers: { … } } }` oder das Modul `nuxt-security`. CSP so wählen, dass `lightweight-charts` und die SSE-Verbindung weiter funktionieren.

## Fertig, wenn

- [ ] Header kommen bei jeder Seite an; Chart und Live-Kurs funktionieren.
